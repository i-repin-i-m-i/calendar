# Жизнь в неделях — Life Weeks Wallpaper

Веб-приложение для генерации динамических обоев iPhone, визуализирующих прожитую жизнь в неделях.

## Возможности

- Генерация изображений под размер экрана iPhone (1170×2532)
- Динамическое обновление — текущая неделя автоматически выделяется синим
- Статистика: процент прожитой жизни, годы прожитые/оставшиеся, номер недели
- Минималистичный дизайн в стиле Apple
- URL-параметры закодированы в base64 для безопасности

## Установка

```bash
pip install -r requirements.txt
python app.py
```

Сервер запустится на `http://localhost:5000`

## Деплой

### Вариант 1: Railway / Render / Fly.io

1. Создайте аккаунт на платформе
2. Подключите репозиторий или загрузите файлы
3. Платформа автоматически обнаружит Flask-приложение
4. Получите публичный URL

### Вариант 2: VPS / Собственный сервер

```bash
# Установка
pip install -r requirements.txt gunicorn

# Запуск
gunicorn app:app -b 0.0.0.0:8000
```

### Вариант 3: Docker

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt gunicorn
COPY . .
CMD ["gunicorn", "app:app", "-b", "0.0.0.0:8000"]
```

## Настройка iOS Shortcuts

1. Откройте приложение **Команды**
2. Перейдите в **Автоматизация** → **+**
3. Выберите **Время суток** → установите время → **Еженедельно** → понедельник
4. Добавьте действие **Получить содержимое URL** → вставьте ссылку на изображение
5. Добавьте действие **Задать обои** → **Экран блокировки**
6. Отключите «Спрашивать до запуска»

## API

### GET /image/{encoded}.png

Генерирует PNG-изображение с визуализацией жизни.

Параметр `encoded` — base64-строка формата `{YYYY-MM-DD}|{age}`:
- `YYYY-MM-DD` — дата рождения
- `age` — ожидаемый возраст

Пример: `MjAwMS0wNi0xNXw4MA==` → `2001-06-15|80`
